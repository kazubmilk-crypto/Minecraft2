# MinecraftBot

Полноценная система управления ботами для Minecraft 1.16.5 сервера с веб-панелью, AI чатом, PvP и автоматическим обходом капчи.

## Возможности

- **Веб-панель управления** — HTML панель на порту 3000
- **Автоматическая регистрация/логин** — бот сам проходит аутентификацию
- **Обход LobbyCaptcha** — читает цифры на бумагах через NBT и кликает по порядку
- **Переход на сервер** — автоматически отправляется `/server grief-1` после капчи
- **AI чат** — Groq API (Llama 3.3 70B), отвечает когда бота упоминают в чате
- **AI Agent** — 18 инструментов, автономный цикл действий
- **Случайная ходьба** — 7-состояние движение, независимый обзор головы
- **PvP режим** — криты с прыжком, автоматический тотем и золотые яблоки
- **Массовое создание** — пакетное создание ботов с задержкой
- **Ротация** — автоматическое добавление/удаление ботов (английские ники)
- **Реконнект** — экспоненциальная задержка при переподключении

## Установка

```bash
npm install
node server.js
```

Открой панель: `http://localhost:3000`

## Настройки

В `bot.js`:
- `SERVER_HOST` — хост сервера (по умолчанию `srv12.vrhosting.su`)
- `SERVER_PORT` — порт (по умолчанию `25263`)
- `AI_API_KEY` — ключ Groq API
- Пароль ботов: `zons123123`

## Структура

```
bot.js       — основной класс бота (капча, AI, PvP, движение)
server.js    — HTTP API + веб-панель
panel.html   — HTML управления (встроен в server.js)
usernames.js — генератор латинских ников
```

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/bots` | Список всех ботов |
| POST | `/api/bot/add` | Добавить бота `{"username":"..."}` |
| POST | `/api/bot/remove` | Удалить бота `{"username":"..."}` |
| POST | `/api/bot/start` | Запустить бота |
| POST | `/api/bot/stop` | Остановить бота |
| POST | `/api/bot/join` | Перейти на сервер `{"username":"...","server":"grief-1"}` |
| POST | `/api/bot/command` | Команда `{"username":"...","command":"..."}` |
| POST | `/api/bot/behavior` | Включить/выключить поведение |
| POST | `/api/bots/batch` | Массовое создание `{"count":5,"delay":30}` |
| POST | `/api/rotation` | Включить/выключить ротацию |
